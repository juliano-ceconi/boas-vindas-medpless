# Folheto Digital de Boas-Vindas — MedPless Assist

Material digital institucional de acolhimento e apresentação aos pacientes e clientes da MedPless Assist (Dr. Ricardo Plessim / Medicina Integrada).

## Visão Geral

- **Propósito:** Apresentar a proposta de valor, corpo clínico, diferenciais do atendimento integrado e canais de contato.
- **Status:** Entregue ao cliente / Portfólio estático.

## Stack Tecnológica

- **HTML5:** Estruturação semântica em arquivo único (`index.html`).
- **CSS3 Vanilla:** Estilização integrada com regras de impressão (`page-break`), responsividade e identidade visual da marca (paleta verde `#154734` e dourado `#FFD700`, tipografia Open Sans via Google Fonts).
- **Dependências:** Nenhuma (zero build / zero runtime dependency).

## Como Executar

No host local (Windows), via Git Bash ou PowerShell:

```bash
# Opção 1: Abrir diretamente no navegador padrão
start index.html

# Opção 2: Servir via servidor HTTP local
python -m http.server 8080
# Acessar: http://localhost:8080
```
